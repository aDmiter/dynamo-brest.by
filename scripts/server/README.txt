Скрипты для сервера (без вставки в терминал)
============================================

Скопируйте папку scripts\server на сервер в:
  C:\dynamo-brest\scripts\server

Через AnyDesk: Передача файлов (File transfer), не буфер обмена.
Или скопируйте с рабочего ПК папку D:\Project\dynamo-brest\scripts\server

Запуск: двойной щелчок по .bat в Проводнике Windows.

Порядок:
  01-check-docker.bat  — проверка билетов и MySQL
  02-start-mysql.bat   — если dynamo-mysql не запущен
  03-seed-menu.bat     — меню и CMS-страницы
  04-start-site.bat    — сайт (окно оставить открытым)
  05-open-site.bat     — открыть браузер

C:\ATS не трогать.
